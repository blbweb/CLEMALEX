Les identités remarquables

Voici les trois égalités à connaître :

(a + b)² = a² + 2ab + b²

(a − b)² = a² − 2ab + b²

(a + b)(a − b) = a² − b²

Exemple : (x + 3)² = x² + 6x + 9.

Teste tes connaissances

Choisis une réponse pour chaque exercice, puis valide pour voir ton score et la correction.

1. Développer (x + 3)²
Bonne réponse : x² + 6x + 9. On utilise a² + 2ab + b².
2. Développer (2x − 5)²
Bonne réponse : 4x² − 20x + 25. Avec a = 2x et b = 5, on obtient a² − 2ab + b².
3. Factoriser x² − 49
Bonne réponse : (x − 7)(x + 7). Car x² − 49 = x² − 7², une différence de deux carrés.
